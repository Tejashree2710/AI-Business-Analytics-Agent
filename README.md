
# AI Business Analytics & Decision Support Agent

An AI-powered business intelligence platform that enables organizations to interact with business data using natural language.

## Project Objective

To build an agentic analytics system that converts natural-language business questions into appropriate data queries and analytical workflows, retrieves relevant business information, explains results, identifies trends and anomalies, and generates actionable recommendations.

## Technology Stack

- Python
- FastAPI
- React
- PostgreSQL
- Redis
- LLM
- LangChain
- LangGraph
- RAG
- pgvector
- Tailwind CSS
- Git and GitHub

## Core Features

- AI-powered business question answering
- Agentic AI workflow
- Natural-language SQL analytics
- Retrieval-Augmented Generation (RAG)
- Business trend analysis
- Anomaly detection
- Actionable recommendations
- Interactive analytics dashboard
